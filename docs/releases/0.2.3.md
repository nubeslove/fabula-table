全新安装与在线更新版本。

- Windows 完整包新增 install.bat、start.bat、stop.bat；自动申请管理员权限。
- 全新安装可以接管旧 FU 后台任务，在新目录建立空账号与空世界。修复用户桌面路径导致的后台启动权限问题。
- 大厅新增“服务器管理”，使用独立管理密码；支持查看版本、检查 GitHub 发行、手动更新并重启。
- 默认每天检查更新；所有世界无人且持续空闲 10 分钟才自动更新。联网检查期间重新进入世界会推迟更新。
- 校验下载与每个文件，备份程序、账号、世界和素材。新版启动失败时回退；更新中断后再次启动会恢复上一版。
- 停止 BAT 会暂停开机自启与自动更新；启动 BAT 恢复后台运行。
- 包含此前的大厅、世界密码、扩展职业、规则分级目录、人物卡、方格探索、五类日志、冲突命刻及行动抽屉。

首次安装：下载 fabula-table-0.2.3.zip，解压到新的固定目录后双击 install.bat。不要覆盖旧数据目录。运行环境由安装器准备，玩家只需浏览器。

以后更新：大厅 → 服务器管理，密码取自服务器 .env 的 FU_ADMIN_KEY。原世界、账号与上传素材会保留，不需要重新安装。
