# 浅绿实装与基础怪物库

用户已在 2026-10-15 明确授权：demo 完成后直接实装，不再等待第二轮批准。当前版本 0.3.0。

## 实装范围

- 沿用已审阅浅绿 Demo 2：舞台优先、无整页滚动、白绿面板；实际参战名单驱动阵列，人数增加时采用两排和分页，立绘不互相覆盖。
- 冲突上左／下右空白处显示大命刻；人数较多、窄屏或行动抽屉打开时收纳到左右抽屉。GM 的加减始终是手动命令。命刻目录放大并支持搜索和世界／冲突分类。
- 聊天骰子移至输入框上方，发送按钮保持固定宽度；各频道黄色感叹号提示未读。保留无角色单／双骰和 Enter / Shift+Enter。
- 角色资源加入泽尼特；能力、法术、职业技能、扩展资源使用目录与详情栏。新增 45 条核心法术／奥灵，保留名称、消耗、目标、时长、完整效果和来源。
- 装备槽：主手、副手、防具、饰品。背包支持同类多件、自定义武器、双持与双盾；双手占两槽但只结算一次。同一单手条目双持需数量至少两件。背包装备不提供穿戴加值。私设保留手动裁定，不自动结算双持攻击或法术消耗。
- 旧 `equipment` 列表保持可读；在首次调整背包时生成 `inventory` 和 `loadout`。不批量重写用户存档；服务器验证槽位、引用和数量。NPC 私有装备与能力不会发给普通玩家。

## 素材与目录

六个用户资源包保存在用户 Downloads；工作副本在被 Git 忽略的 `output/imports`。不提交原压缩包或 PDF。

基础资源分为怪物和场景，并按素材包、类型和换色／阴影分组。共有 362 条：Pipoya 310 条、JW608Art 40 条、Starmage 3 条、Moose n’ Stoat 9 条（三场景 × 完整／前景／背景）。重复分辨率保留清晰版本，透明 WebP；Pipoya 去除透明空边，不裁去图像内容。完整图用于默认场景选择，分层供 GM 自行使用。缩略图分页懒加载，舞台只下载实际引用图片。基础库不写入每个世界的 GM 素材，原世界素材仍走原授权／缓存机制。

目录 ID 根据来源路径生成；图片文件名为内容散列。压缩改变不改变资源 ID。导入脚本：`scripts/import-base-art.py`。

素材版权仍归原作者，应用素材页逐项署名。出处和限制见 `public/library/CREDITS.md`。应用内使用不将原素材包改称本项目原创资源；不额外发布可独立贩售的素材包。

升级沿用现有 0.2.x Windows 程序更新与备份流程，保留 data、.env、runtime、账号、世界与用户素材。基础资源随应用更新，规则正文维持原独立包。服务器是否已升级必须以服务器管理页为准，本机发布不代表已替用户操作远程服务器。
