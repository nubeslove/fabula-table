修复 Windows 全新安装被旧后台任务阻挡的问题。

- 旧 FU 文件夹已删除、移动或程序文件不完整时，安装器可根据完整的原 FU 任务记录接管残留任务。
- 继续核对任务名称、任务位置、FU 安装说明、启动入口和工作目录，避免修改其他程序；已有程序标识发生冲突时仍会停止。
- 安装错误现在会显示旧任务指向的具体目录和缺失的文件。
- 保留 0.2.3 的停止 BAT、网页手动更新、每日无人自动更新、备份和失败回退功能。

如果 0.2.3 安装提示“无法确认原后台任务属于 FU 安装”，请下载完整的 fabula-table-0.2.4.zip，解压到新的固定目录，再运行 install.bat。无需手动删除后台任务。

此修复在安装器中。已经正常安装并运行的服务器无需重新安装；网页更新仍会保留账号、世界和素材。
