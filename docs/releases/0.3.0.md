# 最终物语 0.3.0 · 浅绿物语桌与基础怪物库

浅绿界面 demo 正式接入世界数据。人物不再挤在固定四人格里，命刻和角色条目按需展开，保留半自动跑团方式。

- 冲突阵列随人数调整，敌方较多时两排，小屏分页；下一轮入口更明显。
- 大尺寸装饰命刻、左右场景抽屉，以及可搜索分类的命刻目录。
- 聊天骰子放到输入框上方，发送按钮固定宽度，频道未读采用黄色感叹号。
- 角色资源显示泽尼特；主副手、防具、饰品装备槽与背包，支持双持、双盾、自定义武器。
- 能力与法术采用目录／详情阅读，整理 45 条核心法术和奥灵，标注 20230207 核心书来源；扩展条目同样可在详情栏阅读。
- 加入 362 个分类基础资源条目：怪物、换色／阴影版本、蘑菇森林／晴空草岩／王座厅及其分层。WebP 与缩略图按需使用，素材署名保留。
- 8 个可编辑预制怪物：灰吼、吸血蝙蝠、小恶魔、温和软泥怪、德拉克、骷髅法师、骷髅士兵、诅咒南瓜。进入“人物 → 预制怪物”选择后加入世界。

已有服务器：管理页检查更新并安装。也可解压独立 upgrade 包，运行 upgrade-windows.cmd，选择原部署目录；升级会备份并保留世界、账号、配置和 GM 素材。首次安装使用完整包中的 install.bat；停止使用 stop.bat。

这次只提供应用内的资源整合，不另行发布原始素材包；第三方美术版权及限制见 app/public/library/CREDITS.md。
