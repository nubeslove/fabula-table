# 最终物语 0.3.1 · 恢复操作面板，修正冲突舞台

- 去掉冲突人物周围的大面积背景与边框，保留立绘、名称、数值和轻量选中提示。
- 命刻默认隐藏在场景边缘，只显示左右小箭头。点击后横向滑出无底板刻度盘，再点收起；数量较多时分页。底部“能力”旁增加 GM 创建命刻按钮。
- 恢复 demo 的快捷行动面板：攻击、防御、装备、物品、常用能力和详情入口。完整角色面板采用紧凑人物资源栏、页签和装备槽／背包／详情三栏，沿用浅绿配色。
- 人物、NPC／怪物、场景和世界素材增加右键删除及“更多”入口，删除前说明影响。玩家只能删除自己的角色；场景和素材由 GM 管理。
- 删除人物清理战斗、探索、Token 和台词引用；删除活动场景回到空白舞台；删除素材解除本世界引用，不影响其他世界。历史记录保留。
- 基础攻击、防御及物品声明仍手动结算，不自动扣资源。

已有服务器在管理页检查更新并安装；也可使用独立 upgrade 包中的 upgrade-windows.cmd，选择原部署目录。升级前自动备份，保留账号、世界、配置与 GM 素材。首次安装使用完整包，stop.bat 用于停止服务。
