# 最终物语 0.3.2 · 小剧场演出模式

探索与冲突现在可以随时开启小剧场。GM 在场景上沿点「小剧场」，选择登场人物后拉开帷幕；场内聊天会同步到共用台词框，说话者突出，其他立绘退到背景。

- 最多六位公开人物，按玩家／非玩家分类选角，支持顺序调整。窄窗口按组显示，并跟随当前说话者。
- 紧凑换角、GM 旁白、角色表情、立绘镜像与预制下一句；Enter 发言，Shift+Enter 换行。
- 共用台词框支持中文换行、逐字呈现和立即显示全文；可以关闭动画。
- 「暂收立绘」只影响自己的画面；「谢幕」结束全团演出。名单、预制台词与历史聊天保留。
- 场外聊天和未登场人物的场内消息不打断演出；玩家只能控制自己的角色。
- 战斗操作面板打开时，小剧场临时避让；探索回合和格子移动保持原状。
- 旧贴图场景、角色表情和台词继续保留，旧世界不会擅自开启小剧场。

大厅 → 服务器管理 → 检查更新，可保留账号、世界和素材升级。首次安装仍使用完整包；更新无需重新创建世界。服务器更新完成后刷新网页。

验证：类型检查、构建、70 项测试通过；浏览器检查探索／冲突、六人登场、换角与表情、镜像、台词、地图移动、战斗面板避让及多个窗口尺寸；本地 GM／玩家真实接口验证同步与权限。
