# 大厅声音与幻想边饰

## 已确认范围

声音接入正式程序；边饰先交付三个可切换 demo，不替换正式界面。继续使用白绿浅色、单屏游玩、地图与立绘优先、有界抽屉。

用户选择「宁静启程」：钢琴、竖琴与轻弦乐；登录／大厅播放，进入世界停止。交互音效短而轻，世界内进一步减弱，不给打字、远程聊天或每次同步附加声音。

## 参考与应用

- 音乐：[Style of Harp](https://opengameart.org/content/style-of-harp)，Umplix，CC0。作者标注竖琴、大提琴、钢琴，原文件 82.125 秒。采用压缩网页音频，轻淡入淡出，循环之间保留自然呼吸；不把原始 WAV 放入安装包。
- 音效：复用共坠群星项目原创合成的 hover／press／open／back 短音，无第三方采样。
- 实际查看了现有 Dawn Atelier 材质板：角饰和延展边线分离，双层细线营造厚度，中心区域保持干净。Kenney Fantasy UI Borders（CC0）也采用这种分离结构。
- [Met 星盘](https://www.metmuseum.org/art/collection/search/923639)：同心刻度与镂空星轮，作为星仪方案结构参考。馆藏图像请求未成功在浏览器显示，不宣称完成图像细节研究。
- [UMMA 花饰手稿页](https://umma.umich.edu/objects/floriated-bible-leaf-2015-2-2ab/)：馆藏说明中的叶蔓金饰作为手稿方向参考；不复制馆藏图片。
- [Met 古典装饰设计](https://www.metmuseum.org/art/collection/search/363177)：莨苕卷草、棕叶与贝壳纹作为王庭方向参考；不复制馆藏图片。

三套使用项目原创 SVG 纹样和 CSS 材质，不下载整套美术包。所有装饰 pointer-events:none，不挤压文字或覆盖立绘。

## 声音清单

| 事件 | 表现 | 默认电平 |
| --- | --- | --- |
| 大厅首次操作 | 音乐渐入，浏览器禁止自动播放时明确显示点按播放 | 音乐 28% |
| 进入世界 | 立即停止大厅音乐并归零播放位置 | 0 |
| 隐藏页面 | 暂停音乐和交互声音；返回大厅页面可继续 | 0 |
| 按钮掠过 | 短音，180ms 间隔，同一按钮子元素不重复 | 大厅 18%，世界 6% |
| 点击／键盘激活按钮 | 轻触音，最多两路，80ms 间隔 | 大厅 30%，世界 10% |
| 音量设置 | 大厅音乐与交互音效各自启停，音量本地保存 | 不影响 GM 场景音乐 |

## 制作与验收

1. 转换音乐并记录来源、时长、峰值；复用短音。
2. 独立声音控制器、设置小面板接入大厅／世界，检查切换和慢加载竞争。
3. 基于既有交互 demo 制作三套完整边饰，同一内容与布局，提供大厅试听、游玩与角色卡切换。
4. 浏览器检查三个方案、抽屉、窗口适配、音乐实际播放状态及进入世界停止；运行类型检查、声音行为测试和构建。

不以声学数值代替听感；当前工具不能主观试听，最终音色由 demo 的试听入口供用户判断。

## 实现与验收记录

- `src/lib/interface-audio.ts` 管理本机声音，`InterfaceSound.tsx` 处理用户手势、页面可见性与设置；App 只提供大厅／世界状态。世界音乐不接入此控制器。
- 音效对象复用，最多两路；设置损坏时恢复默认值，音量限制为 0–100。
- 音乐 44.1 kHz 双声道、约 82.125 秒、960,205 字节；转换后平均 -23.9 dBFS、峰值 -6.1 dBFS（文件电平，不代表听感响度）。运行时大厅默认增益 0.28；世界交互声按大厅的三分之一。
- 5 项声音行为测试通过：首次手势、进入世界停播、异步播放竞争、后台暂停、世界音量／节流／叠音、独立开关；HTTP 验证 `/fu` 前缀、正确 Ogg 类型、头部／尾部范围读取与无效范围。
- 浏览器实测曾发现原生计时器以对象方法调用引发异常，已改为显式包装；再次确认真实媒体 paused=true、currentTime=0，世界点击增益 0.1、悬停 0.06。
- 1280×720 与 1024×768 下检查大厅、游玩、能力目录和装备抽屉，根页面尺寸与视口一致。边饰不参与命中、不遮挡立绘；冲突命刻默认隐藏，只保留边缘小箭头。
- 样板源码在 `demos/fantasy-ui/`；原始音源在忽略目录 `output/research/`，截图在 `output/fantasy-*.png`，不进入发行包。

声音随 0.3.6 发行，三套视觉皮肤等待用户选择后再进入正式界面。
