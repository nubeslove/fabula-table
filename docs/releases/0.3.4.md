# 最终物语 0.3.4 · 左右小剧场与预制动作

小剧场立绘现在分列台词框左右两侧，底端贴齐台词框上沿。每侧可站多名角色，错开排列；正在说话的人提亮、稍放大，地图中央保留空间。

- 「走位」新增「到最左边／到最右边」，约 320ms 快速滑到对应边缘；同侧人物自动顺位。Alt+左右键直接换边，Shift+Alt+方向键微调，Alt+Home 归位。
- 新增 12 个「动作＋表情」预设：震惊、开心、生气、害怕、疑惑、点头、摇头、鞠躬、沮丧、得意、撒娇、瞌睡。每次播放一个短动作，点击可重播，「停稳」立即结束动作；关闭动态时保留表情。
- 站位、动作和表情同步给全团；GM 控制全部登场人物，玩家控制自己的角色。刷新恢复站位，不重播已有动作。
- 保留角色表情立绘、通用表情、镜像、共用台词框和场内聊天同步。演出不会移动地图 Token 或扣除移动格数。
- 窄屏沿用立绘分组切换；修复立绘层级盖住操作浮层的问题。

从大厅的服务器管理升级；也可以运行先前下载的 update.bat 自动获取最新正式版，或下载本页的 upgrade 升级包离线升级。保留账号、世界和素材。更新完成后刷新网页。

验证：8 项小剧场针对性测试、类型检查与构建通过；浏览器检查六人左右分组、快速换边、12 种动作、停稳、受限窗口和工具遮挡。
