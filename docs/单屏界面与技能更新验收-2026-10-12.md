# 0.1.3 单屏界面与设计技能更新验收

来源：2026-10-12 用户明确要求全屏游玩不出现整页滚动、提高场景空间利用率，并从插件市场与 GitHub 更新前端设计技能。实现方案见 [单屏游玩与面板](design/单屏游玩与面板.md)。本轮仅改 FU 界面及明确要求的通用设计约束；共坠群星原自主审查仍暂停。

## 界面交付

- 游戏壳固定于可用视口，舞台按剩余高度伸展；外围边距缩至 4～6 px，去掉舞台下方引导卡片和重复工具条。
- 首次建卡使用可关闭弹窗；人物、场景、工具、日志、规则书、素材改为抽屉，保留舞台及台词草稿。
- 聊天栏可收起，窄屏改浮层。主要命刻的名称和进度保留在舞台上沿；完整说明和管理进入弹窗。
- 导演控制压缩为角色选择、快捷换角和输入；低频操作从演出设置展开。台词可收起，新台词到来后展开。
- 背景按完整画幅显示，探索 Token 与媒体共享坐标区域。没有新增自动裁定、命刻推进或战斗结算。

## 真实浏览器检查

| 视口 | 根节点 clientWidth / scrollWidth | 根节点 clientHeight / scrollHeight | 结果 |
| --- | --- | --- | --- |
| 1366 × 768 | 1366 / 1366 | 768 / 768 | 舞台、命刻、聊天、输入同屏 |
| 1280 × 600 | 1280 / 1280 | 600 / 600 | 较矮窗口仍可访问两处输入 |
| 390 × 844 | 390 / 390 | 844 / 844 | 菜单、命刻和输入在视口内；聊天按需打开 |
| 当前默认 605 × 884 | 605 / 605 | 884 / 884 | 演出设置浮层不撑高页面 |

在 1366 × 768、聊天展开时，舞台约 1054 × 556 px；导演区下沿为 762 px，聊天输入下沿为 768 px。根页面没有横纵滚动；长内容保留面板内部滚动。

实际操作覆盖：首次建卡引导显示／关闭；建卡弹窗保存角色；人物登场；抽屉 Esc 关闭后焦点回到入口；台词草稿未丢失；规则书在抽屉内阅读；窄屏聊天开关、草稿保留和重新打开后跟随最新消息（末尾距离 0 px）；三枚命刻和长命刻名；命刻详情保存后名称恢复；台词收起；导演切换发言角色；背景和透明立绘上传及应用。

探索模式中测得媒体与 Token 坐标层的边界完全一致：桌面约 988.8 × 556.2 px，390 px 窄屏为 382 × 214.875 px，保持 16:9。角色的相对坐标在窗口和聊天栏变化后保持一致。本轮没有把该检查表述成重新完成全部多人端到端验收。

截图与测量在忽略目录：`output/fu-single-screen-desktop-0.1.3.png`、`output/fu-single-screen-mobile-0.1.3.png`、`output/fu-single-screen-layout-0.1.3.json`。截图使用本地演示世界，测试素材不进入发行包。窄屏由桌面浏览器模拟；真实手机软键盘与安全区仍需真机团测。
