# 最终物语 · 浅绿 JRPG 交互 Demo 2

这是独立的界面原型，用于审阅舞台布局与角色卡。不会连接正式服务器、读取真实世界或修改账号。所有操作只在当前页面中保留，刷新后恢复演示数据。

## 打开

解压整个文件夹后双击 `index.html`，不需要安装依赖或联网。也可在此目录运行 `python -m http.server 3354 --bind 127.0.0.1`，打开 `http://127.0.0.1:3354/`。

地址加 `#gear` 直接打开装备卡，加 `#spells` 直接打开法术卡。

## 建议试用顺序

1. 顶部切换演出、探索、冲突。演出中点击角色切换说话者；探索点亮格移动，右下方结束回合并恢复移动格数。
2. 冲突画面点击“行动 ↑”，打开较矮的快捷抽屉。选法术、声明使用，再点“阅读条目”进入完整详情；聊天和舞台不锁定。
3. 打开角色卡，资源条固定显示 HP、MP、IP、物语点和泽尼特；能力与法术采用左目录、右详情。可搜索“精神”或“盾牌”。
4. 装备与背包中切换双武器、双盾、双手样例。选择物品可以装备、卸下或记录私设。双手武器的两个手部栏关联同一件物品；卸下会同时释放两栏。
5. 命刻悬停或键盘聚焦后出现加减按钮。“全部命刻”查看完整目录；冲突命刻留在对应半场。
6. 聊天支持 Enter 发送、Shift+Enter 换行、单／双骰。点击聊天标题旁的模拟消息按钮，可查看其他频道的感叹号提示。顶部书本图标打开手记。

## 演示边界与规则来源

- 莉娜是完整角色卡样例；雷恩、伊芙是简短资料与演出样例，不是已完成的多人建卡系统。
- 六个条目用于验证阅读结构：四个法术／奥灵、双重盾牌、双武器速查。尚未导入全部职业法术目录。
- 门径奥灵、加速术、精神汲取按用户提供的卡面样例整理；与本地旧核心译本有数值、名称或效果差异，详情保留来源提示。正式整合时需要规则版本与来源字段。
- 四装备栏、双武器、双重盾牌来自本地 FU 核心资料；自定义武器来自全扩展资料。双盾示例基于“双重盾牌”技能；自定义武器默认双手且不受灵猴握影响。私设入口不替 GM 作装备资格判定。
- 数值、换装和行动都是示例状态；不会自动结算伤害、扣除资源或推进命刻。
- 探索是 15×10 方格示例，每轮 2／4／6 格可选，正交移动，墙体不可穿越。没有距离单位。

## 素材与技术

纯 HTML、CSS、JavaScript，无外部字体、CDN、依赖包或联网请求。

- `assets/observatory.svg`：本 demo 绘制的代码矢量场景示意。
- `assets/silver-wayfarer.webp`：复用本地 AAF 已有生成立绘 `game/assets/portraits/aaf/silver-wayfarer.png`，压缩为 WebP，仅作界面样例。
- 其余人物为有姓名的二维 token；未使用女神异闻录等商业游戏图片作为发布素材。

详细参考、FU 页码与验收记录见仓库 `docs/design/JRPG界面与角色卡-demo-2026-10-14.md`。
