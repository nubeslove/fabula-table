# 幻想边饰与声音 · 三套对比 demo

打开 `index.html` 即可离线查看。顶栏切换「精灵手稿」「星仪魔法」「古典王庭」，布局、内容和样例人物保持一致。

- 大厅：查看材质与边饰；点击「试听大厅音乐」。首次交互后浏览器允许播放。
- 游玩：探索／冲突／演出沿用现有 demo；进入时大厅音乐停止，交互音效变轻。
- 角色卡：直接打开装备与背包，可切换能力法术、人物概览；保留底部操作面板。
- 声音：独立控制音乐和轻触音效。切换到后台暂停；返回大厅继续。

这是边饰比较样板，不保存真实人物／世界，不访问服务器。用户已选定「古典王庭」，0.3.7 将该方案接入正式产品，并修正台词边框遮字；其余两套仍仅用于比较。样例场景与角色沿用项目既有 demo。音乐与音效来源见 `audio/CREDITS.md`。全部边缘、星盘与叶蔓 SVG 为本项目原创矢量纹样；没有捆绑参考馆藏图片。

复现：在项目根目录执行 `node scripts/build-fantasy-demo.mjs`。基础交互来自 `demos/jrpg`；本目录 `fantasy.css`、`fantasy.js` 是本次独立样式与演示入口。

设计与声音规格：[大厅声音与幻想边饰](../../docs/design/大厅声音与幻想边饰-2026-10-15.md)。
