# 0.1.7 方格探索验收

范围：用户要求的可见方格地图、按场景设置移动格数、按回合行动。不使用物理距离单位，GM 保留地形裁定和免费调整位置。

- 新增共享方格计算、服务器回合和额度校验、地图组件及场景配置。旧 Token 百分比坐标兼容并落到格中心；各场景独立保存探索进度。
- 类型检查、构建、探索/世界/HTTP 定向测试共 22 项通过。覆盖越权、超额、多 Token 共额度、重复请求、整轮补满、场景隔离、旧存档和重新读取存档。
- 隔离测试世界验证点击目标格、拖动落格、方向键逐格移动、GM 调位、设置每轮 5 格、玩家结束回合以及玩家与 GM 的实时同步。GM 调位不改已用格数，非当前玩家的结束按钮禁用。
- 1366×768、1280×600、390×620 的根尺寸等于视口，无整页滚动。窄屏回合栏底部为 616px（620px 视口）；地图缩放和平移后棋子中心偏差小于 0.03px。
