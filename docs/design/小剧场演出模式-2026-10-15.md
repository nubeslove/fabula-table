# 小剧场：地图上的视觉小说演出

## 0.3.4 构图修正与预制动作（2026-10-15）

本节覆盖旧的均分列、悬空走位方案。用户再次提供的截图中，堂吉诃德位于左下角，立绘底端与名字靠近台词框上沿；地图中央与上半部保持开放。用户明确选择每侧可站多人，沿上沿错开，当前发言者突出。白绿控制条、共用台词框、镜像和原有表情保留。

- 立绘改为左右成组的绝对站位，底端贴住台词框；名字压在立绘下缘，不另占一行撑出空隙。每组从外向内排，限制轻微重叠，说话者置顶、提亮，听众缩小但脚下基线不变。中央留出地图空间；窄屏保留分组翻页与发言者跟随。
- 左／右走位和 Alt+左／右改成直达台词框左右端，约 320ms 快速滑动。同侧已有人时，新移动者到最外侧，其余顺位。Shift+Alt+方向键仍用于小幅校正，归位恢复当前侧的基线；旧偏移记录保留，仅作有限的边缘微调，避免沿用悬空布局。
- 新增「动作」轻浮层，3 列紧凑按钮；只在操作时展开，不新增常驻大面板。动作与镜像、站位、高亮分层，避免 transform 互相覆盖。每次只播放一个短动作，重复点击重播，新动作替换旧动作。关闭动态后只显示对应表情。

| 疑惑 | 歪头、停顿、回正 | 疑问 | 900ms |
| 点头 | 两次短促下倾 | 开心 | 650ms |

| 鞠躬 | 前倾、停顿、起身 | 无 | 1000ms |
| 沮丧 | 慢慢垂下再恢复 | 难过 | 1100ms |

## 已确认的目标

探索、冲突是主场景，小剧场是其上的可开启模式。GM 先选择登场人物；人物发言时放大、变亮，其他人退后。2026-10-15 用户选择：共用底部台词框；场内聊天同步演出，场外不影响。沿用白绿界面，无大块立绘边框，不恢复旧版挤占舞台的独立输入表单。

## 构图与操作

场景上沿：小剧场入口与状态，独立于场景类型。GM 首次点开为选角窗口，按玩家/非玩家分类搜索；最多六位，支持调整顺序。再次打开可换演员，结束不丢失演员名单与预制台词。

地图下缘：透明人物区 + 共用台词框，底部为原有冲突/探索工具留出约 64px。人物区约舞台高度的 40%，单人上限 320px；六人按可用宽度分配列，当前说话者占更宽一列。名字使用浅色文字和暗色投影。台词底板为深绿半透明局部渐变、细金线与浅色文字，控制条浅白绿；中文 16–18px，约三行可见，长文本只在正文内部滚动。逐字显示可点击立即显示全文，可关闭动画；不逐字发送屏幕阅读器通知。

操作条：紧凑登场头像、GM 旁白、当前角色表情和镜像、预制下一句、选角/结束；玩家仅控制自己的公开角色。选角同步到聊天身份，场内已登场角色发言才驱动舞台；未登场角色仍可场内聊天，避免擅自加入演员。旁白仅 GM。收起只影响本地，不停止全团。台词历史仍在场内聊天。战斗操作面板打开时演出在本地自动避让，关闭恢复，回合与移动规则不受演出影响。

## 后续补充：立绘走位与通用表情（用户明确追加）

用户希望保留参考插件的微调与通用表情，用按键移动表现人物走动。采用已研究的独立立绘偏移方式，不移动地图 Token，不扣移动力。选中自己可控制的登场人物后，Alt+方向键走位，Shift+Alt+方向键细调；控制条的「走位」提供同等的四向按钮（支持按住）、位置读数与归位。聊天输入、弹窗、战斗工作台打开时不拦截移动键。

偏移按舞台比例保存、多人同步，以服务器增量命令处理按键；限制人物留在舞台范围及台词上方。镜像、说话高亮、走位分别嵌套，避免 transform 相互覆盖；名字与表情跟随立绘。窄屏分页保持可读，重新打开或刷新恢复偏移。

「通用表情」为独立于立绘图片的十种漫画符号：开心、惊讶、疑问、生气、难过、爱心、思考、紧张、哼歌、困倦。使用自绘 SVG 与短促过渡，不下载额外贴图；点选同步给全团，可再次点选重播、清除。关闭动态时保留静态符号。和角色原有表情图可同时使用。

本轮一并修正已观察到的立绘压住台词：人物图像绝对定位在有界区域内，外层负责走位，台词层独立置顶；不是靠整体缩字或裁切操作区处理。
