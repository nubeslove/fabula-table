# 目录、战斗与资料工作区

依据 2026-10-12 用户对场景过多、命刻挤占聊天、战斗场景、规则书和素材面板的五项反馈。交付版本 0.1.4，范围为 FU 独立站。

## 场景目录

`SceneDirectory` 将搜索、类型筛选、新建按钮固定在上方，分类目录与条目列表各自有界滚动；GM 世界手记和导出入口固定在下方。场景名称、模式、人数／Token／台词数量与当前场景标识在一行条目中可查。缩略图只辅助识别，不再占半张卡片。

`Scene.folder?: string` 为可选 GM 准备信息。服务器去除首尾空白，限 60 字；旧存档和旧客户端未传时默认空字符串，不要求迁移。玩家投影视图清空此字段，以免泄露后续章节名称。场景版本冲突与既有保存权限沿用原合同。分类由现有场景生成，在场景编辑器可选择已有名称或填写新名称；没有单独的空目录实体。

## 二维冲突舞台

`battle.active` 或当前场景 `mode === battle` 时主舞台使用 `BattleStage`。背景沿用本幕完整图像或视频；我方左下、对方右上。立绘用 contain 保持比例，不强制镜像含字 Token；无素材时显示角色首字标记。每侧最多四人一组，更多人通过翻组查看；当前行动者变更时自动切到其所在组。

点击角色只切换本地查看对象。GM 的“让此角色行动”和“结束当前回合”分别调用已有手动指令。底部固定显示选中人物与能力／掷骰／资源入口，弹窗由 `BattleAction` 承载。声明能力不消耗 MP，掷骰不扣 HP，不自动选目标或判命中；服务器保持最终权限检查。玩家只操作自己控制的人物，NPC 隐藏数值不显示成假的零值血条。错误显示在操作弹窗内。

战斗中默认收起导演输入，通过舞台上沿“台词”按钮恢复；舞台与草稿不销毁。冲突设置仍可管理参战状态与结束冲突；开始后关闭设置面板，直接展示战斗。原有交替行动与人数不等时剩余行动规则不变。

## 规则阅读与素材

规则阅读器使用分级章节目录、固定搜索／资料选择、独立正文与底部分页。搜索使用重排文本并连接 PDF 断行；资料页和印刷页同时保留。窄屏目录按需覆盖在阅读区域中。

`scripts/structure-core-book.py` 从本地原书几何位置提取标题层级、段落、列表与可识别表格。核心书 362 页生成网页文本；已有原始提取正文仍保留供对照。表格按原书列标题与坐标恢复单元格，保留数值，替换特定字体中的装备图标。导入流程调用此脚本；本地导入需要 PyMuPDF。原 PDF 不复制进资源包。

扩展资料没有几何结构时使用保守段落重排，不猜测数值表格。全文翻译与所有复杂页尚未逐页校订，不应把格式转换称为规则校勘。原始文本开关与来源页码用于核对。原有纯图片页仍提示无正文。

素材管理器将上传、搜索、媒体类型筛选固定在顶部；中部为小缩略图文件条目，底部固定选中数量和分享入口。邀请与预下载使用独立页签。图片／音视频可在预览窗打开，保留原有压缩、去重、缓存、预下载权限与密钥更换逻辑。图片清晰度选项只影响后续上传。
