# 最终物语 0.3.6 · 宁静启程与轻声交互

登录与大厅加入钢琴、竖琴和大提琴背景音乐；进入世界后立即停止。按钮轻触与点击增加短音，世界内音效默认降为大厅的三分之一，减少对思考与语音的干扰。

- 大厅和世界顶栏均可打开声音设置：音乐、交互音效分别启停和调音量，选择保存到本机；不改变 GM 的场景音乐。
- 首次点击或按键后播放大厅音乐；切换到后台暂停，返回大厅可继续。连续触碰有间隔限制，最多两路短音，重复声音复用播放对象。
- 大厅音乐约 960 KB，全部为压缩网页音频。Style of Harp — Umplix（CC0），音效来自项目原创合成素材。来源随包保留。
- 浏览器可按字节范围读取音乐，正确获取时长与循环位置。

另外制作「精灵手稿／星仪魔法／古典王庭」三套白绿浅色边饰 demo，包含大厅、游玩和角色卡。它们是独立比较样板，本次升级不更换正式游玩界面的皮肤。

验证：声音状态与竞争条件测试、HTTP 音频范围请求检查、类型检查和构建通过；浏览器确认大厅实际播放、进世界停播、世界轻声音量和单屏布局。不能以声学测量代替主观试听，可在声音面板自行试听。

通过服务器管理或 update.bat 更新；下载慢时使用本版 upgrade ZIP，解压到独立文件夹后运行 upgrade-windows.cmd，选择原安装目录。保留世界、账号、素材和配置；更新完成后刷新网页。
