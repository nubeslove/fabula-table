# FU 独立站：审计与实施方案

日期：2026-10-11。来源为本次用户请求及其后续资源同步、独立部署包要求。此前共坠群星自主审查继续暂停。

## 1. 概念总览

最终物语的轻量联机跑团桌。GM 主持、玩家共同叙事，优先尽快可用。独立目录 `E:/project/FabulaUltima`，不增加共坠群星规则注册项、不载入 DND／AAF／LANCER 包。先交付网页和独立的一键部署包；用户自行复制到现有服务器运行，无需现在连接服务器。原生 EXE 不在本次交付范围。

## 2. 核心循环

创建房间 → 玩家加入／自动建卡 → GM 准备场景、人物、台词与命刻 → 演出／探索 → 必要时进入冲突 → 玩家声明、掷骰、GM 裁定与手动调数值 → 回到叙事 → 保存并导出备份。

## 3. 模式划分

仅 GM 主持模式。演出、探索、冲突是同一世界的三种展示方式，共用角色与日志。演出时可调出角色和骰子，不强制关闭对话；没有无 GM 模式、肉鸽、距离战斗规则或自动 AI 裁定。

## 4. 系统设计

2026-10-12 用户明确收拢定位：网站主要辅助战斗、探索和日志记录；物语点改写故事由玩家与 GM 聊天协商，代码只记数量与操作。命刻及线索的本次实现合同见 [命刻与冒险日志](命刻与冒险日志.md)。这一要求覆盖此前可能扩展出的自动剧情判断或自动推进方案。

- 建卡：身份／主题／起源，DEX／INS／MIG／WLP，2～3 个起始职业和 5 个等级，职业技能、装备、HP／MP／IP、物语点、羁绊。常规模式校验核心规则；私设模式允许额外职业、数值修正和自定义能力，并明确保留修改。
- 冲突：GM 先勾选本次参战者，默认玩家角色与当前场景人物，可全选、清空或仅选本幕；旁观者不计入回合。双方交替选择未行动角色；人数不等时剩余一方继续，每人本轮行动完进入新轮。GM 选择行动者或结束冲突；不会因使用能力自动掷骰、扣血或推进回合。
- 行动：点击能力只发声明；玩家另行掷属性骰或普通骰；GM 手动输入伤害／治疗及资源变化。日志记录操作人与原因，保留明确恢复方式。
- 命刻：GM 创建 4～12 格命刻、增减进度、选择公开；满格只提示，不执行脚本。物语点消耗记录理由，影响叙事由 GM 与玩家协商。
- 演出：常驻导演控制、点击人物切换、1～6 快捷选择、表情与站位、登场／退场、角色独立草稿、预制台词前进／回放。发言者明亮放大，非发言者缩小变暗，保留减少动态效果选项。未播放台词只对 GM 可见。
- 场景：静态贴图可作演出背景；探索使用方格棋盘，按格落位、不换算物理距离。GM 按场景设置每人每轮格数和参与顺序，玩家仅在自己的回合移动持有角色；结束一整轮才恢复额度。详见 [方格探索与回合](方格探索与回合.md)。隐藏场景和 Token 不发给玩家。
- 角色自由编辑与 GM 快速 NPC：可上传头像、立绘与表情；编辑时保留当前资源，改变上限不等于自动回复。

## 5. 数值框架与规则来源

依据用户本地《FabulaUltima_最终物语核心规则书_汉化版20230207.pdf》；PDF 页码比印刷页码多 2。重点核对：建卡 PDF156～173、职业178～221、成长228～243、命刻54～57、回合64～66、物语点98～101。

- 起始属性：8/8/8/8、10/8/8/6、10/10/6/6；初始总等级5，2或3职业。职业10级精通，技能等级受自身上限限制。
- 最大HP＝总等级＋基础MIG×5＋职业／技能／私设修正；危机值向下取最大HP一半。MP以WLP同式；IP基础6；物防DEX、魔防INS，装备按加值或固定替换计算。

## 6. 内容清单与审计结论

现有 `game/apps/desktop/src/story/adventure/StageOverlay.tsx` 提供6人舞台、角色权限、台词与导演抽屉，但依赖整个 ManualTable／冒险合同、素材系统及其他规则。CSS中发言者主要提亮与上移7px，未实现明显缩放；反复开抽屉不适合多角色快切。因此借鉴交互及权限边界，在独立站重做轻量舞台，不复制整套壳。

现有 `product.ts` 只含共坠群星、行于泰拉与新乌托邦分发身份，系统注册没有 FU。直接套用将引入无关规则、巨大资料包与 WebRTC 建链等待。独立站采用服务器持久化与轻量事件同步。

本地来源 `E:/TRPG/FU/` 共核心书、扩展CHM、若干扩展PDF／DOCX与自动化人物卡。原文件只读保留。先使用核对后的核心建卡和职业文本；用户可添加自定义职业、技能、法术、装备与剧情资产。

## 7. 联机与权限

独立房间、GM身份与玩家登录，不要求任何GM或玩家拥有GitHub／R2账号。部署者配置站点后，GM在网页直接上传。服务器校验身份、角色所有权和操作，原子保存后广播按身份过滤的视图；重连取当前版本，不重放危险写入。私密台本和手记不下发。多人编辑使用版本检查避免覆盖。

## 8. 技术约束与资源同步

React＋TypeScript客户端；独立Node服务，发行时打包服务代码，避免服务器重新编译整个共坠群星。状态用JSON，素材二进制单独保存。新服务默认独立端口与路径，部署脚本保护旧数据与既有服务。

资源分三类：程序；官方固定ID与带版本资源包；GM按世界上传的自定义素材。只有第三类走GM世界素材同步。官方资源不随世界重复上传。资源按SHA-256内容寻址去重、浏览器持久缓存、仅下载缺失文件；更新按钮或规则计算不重发大素材。

用户追加的通用资源要求：发行内容不使用原始扫描PDF；完整正文转为分章节网页文本，表格与必要插图保留来源定位。图片压缩为适用尺寸WebP，视频转为WebM／MP4网页格式，音频使用网页压缩格式；转换保留透明、动画、音轨和时长，不牺牲规则可读性。原件仅在用户本地保留作校对。此原则已同步至共坠群星根入口与持久规范。

GM选择预下载素材 → 复制只读预下载链接 → 玩家提前下载并看到总大小／进度／失败重试 → 正式进入同浏览器后复用缓存、自动补新文件。预下载不能取得世界私密数据或未加入清单的素材。链接可轮换。浏览器清理缓存或更换设备需要重新下载；不把浏览器缓存宣传成永久保留。

2026-10-12 补充：浏览器无法存储时，正式房间保留已下载素材的本次显示，并明确提示没有完成持久缓存；预下载则必须保存成功才计为完成。发行同时提供首次部署完整包、程序更新包、官方规则文本包，后两者可独立传输并合并至同一目录。

默认本机／服务器文件存储即可使用；存储访问单独封装，预留R2替换位置。后续接入由站点管理员配置一次，不改变GM／玩家流程。R2免费额度于2026-10-11核对：标准存储10 GB·月、100万写类／1000万读类操作、直接出口流量免费；超额请求与存储可计费。依据 https://developers.cloudflare.com/r2/pricing/ 。本批不承诺已经开通R2或完成其公网验收。

## 9. 美术与音频

2026-10-12 用户追加的前端最高约束：全屏游玩页面不允许整页滚动，舞台保持主体，首次建卡为弹窗，长内容进入抽屉或分层面板。减少容器边距与重复装饰；地图完整展示并保持 Token 坐标一致。该要求覆盖此前手机纵向堆叠方案，详见 [单屏游玩与面板](单屏游玩与面板.md)。

操作区使用暖纸色与深绿，演出区深色、突出人物。图片与音频由GM上传；舞台支持PNG／WebP透明立绘及表情；上传时提供可选压缩与实际大小反馈，不混入其他世界的素材。浏览器播放声音需要用户首次允许。

## 10. 里程碑与验收标准

1. 独立启动、房间创建／加入、重启持久化、权限过滤与官方建卡通过定向测试。
2. 双浏览器完整操作：新建角色、声明／掷骰／GM扣血、交替回合、命刻与物语点；舞台角色切换、表情、私密台本、探索Token同步。
3. GM上传自定义素材，玩家预下载、再次进房缓存命中；修改一项只补该项。未公布资源与私密台本无法从预下载接口取得。
4. 生成独立发行包、启动脚本、Linux一键部署与更新说明；包内不含测试房间、认证信息、作者原始规则附件。验证解包运行。用户未提供服务器环境时，实际远程安装准确标为未验证。
