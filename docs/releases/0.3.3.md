# 最终物语 0.3.3 · 小剧场走位与通用表情

登场人物现在可以在小剧场里走位，并使用不依赖额外立绘图片的通用表情。GM 可以控制所有登场人物，玩家可以控制自己的角色；位置和表情同步给全团，并随世界保存。

- 选中人物后，按 **Alt + 方向键** 移动，另按 **Shift** 细调，**Alt + Home** 归位。也可以打开「走位」，按住方向按钮连续移动、松开停止。
- 走位使用平滑过渡，可表现人物来回行走；仅调整演出立绘，不移动探索 Token，也不消耗移动格数。
- 「通用表情」提供开心、惊讶、疑问、生气、难过、爱心、思考、紧张、哼歌、困倦十种漫画符号。可以与角色的表情立绘叠加，再次点击重播，支持清除。
- 保留镜像、换角、共用台词框和场内聊天同步；聊天输入时不会触发走位快捷键。
- 修复立绘尺寸挤入台词框的问题，调整移动边界和窄屏显示。

大厅 → 服务器管理 → 检查更新，可保留账号、世界和素材升级。服务器升级完成后刷新网页。
