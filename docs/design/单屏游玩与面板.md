# 单屏游玩与面板

依据 2026-10-12 用户对全屏游戏界面的明确要求。此约束优先于此前把手机布局改成纵向长页面的方案。

## 最高约束

游玩根页面不得出现横向或纵向滚动。舞台与场景是持续存在的主体，不能让玩家上下翻页才能看到聊天、输入、命刻或人物操作。不要求把所有功能同时铺满：详细内容进入弹窗、抽屉、弹出菜单和可收起的图层。

禁止单纯隐藏溢出、缩小整个界面或裁掉按钮来通过检查。聊天历史、资料、长表单允许在有明确边界的面板内部滚动，返回舞台后保留草稿与场景状态。正文可读性、关闭入口、键盘焦点和错误提示必须保留。

## FU 界面结构

- 顶栏提供人物、场景、工具、日志、规则书、素材入口。窄屏合并到功能菜单，聊天可以单独收起。
- 舞台按剩余视口高度伸展。外围间距 4～6 px；标题、横排命刻与少量快捷按钮共用一行；发言角色、快捷换角和输入共用紧凑导演区。
- 第一次进入且没有人物时显示建卡引导弹窗，可以关闭后从“人物”重新进入。表单在弹窗中编辑，不在舞台下方堆叠引导卡片。
- 人物、场景、行动与冲突、日志、规则书、素材在可关闭的非模态抽屉中打开；主舞台组件保持挂载。抽屉 Esc 关闭，关闭后焦点回到入口。
- 演出设置使用向上展开的菜单，包含登场／退场、表情、声音、动态与预制台词回放。常用发言角色与台词输入始终可达。最新台词可收起为提示条；新台词到来时展开。
- 桌面聊天栏宽 300 px；小于 1000 px 时改为浮层，收起后恢复完整场景。聊天输入固定在栏内底部，历史独立滚动。
- 多个命刻横排使用场景上沿的剩余宽度；优先显示项在前、其余在后，各组保持原顺序。固定一行，溢出通过翻组查看。点击某个命刻进入其详情，另有全部管理入口；收起聊天后自动增加并排数量。
- 背景以完整画幅适配可用区域。宽高比不同会留边，不裁掉地图边缘。图片／视频与探索 Token 共享同一坐标区域；改变窗口、开关聊天栏不会改变 Token 相对地图的位置。

## 实现边界

`App.tsx` 仅装配会话、弹窗与面板。`TableChrome` 承担顶栏、抽屉和首次引导；`TablePanels` 装配长内容；`SceneMedia` 保持背景与 Token 坐标一致。`game-layout.css` 在基础样式之后加载，限定于 `.game-table`。

场景合同增加可选的 GM 私有目录字段，其他服务器权限、自动建卡公式与手动裁定原则保持。宽屏和窄屏共用相同功能入口；登录页、规则正文与长表单本身不强制一屏显示。

## 验收要求

在常规笔记本、较矮视口和窄屏检查根节点的 scrollWidth/scrollHeight 不超过 clientWidth/clientHeight。同时观察舞台、输入和关闭按钮的真实边界，确认内容没有被裁切。覆盖首次引导、建卡长表单、抽屉开关、草稿保留、优先项及多个命刻、聊天和地图画幅。桌面模拟窄屏不能代替真实手机软键盘测试；尚未完成的项目须明确记录。

## 多内容工作区（0.1.4）

无整页滚动只是底线，不能把长页面原样塞进一个滚动抽屉。场景、素材、规则书分别使用目录／筛选、独立列表或正文、固定底部控制三段结构。

- 场景目录按 `Scene.folder` 分类，条目约 67 px 高；手记和导出入口不参与列表滚动。旧场景字段缺失默认未分类。目录字段仅发给 GM。
- 命刻从聊天栏移出；0.1.5 改为利用舞台上沿整条可用宽度横排，支持多选优先显示和翻组。完整管理按需打开，聊天高度不随命刻数增加而缩小。
- 战斗是主舞台的一种显示状态：我方左下、对方右上，无距离网格。参战人数多时每侧按四人分组；操作栏固定在底部。演出台词按需展开，已行动、当前行动用文字与视觉同时区分。
- 素材条目配小缩略图、类型、体积和预下载勾选。邀请与预下载独立页签，上传按钮、搜索、筛选固定在顶部。
- 规则书分级目录与正文各自滚动，翻页与原始文本入口固定在底部。原书页码保留，正文以语义段落和 HTML 表格重排。

验收至少覆盖一个确实超过列表视口的场景目录和多个命刻；空列表或两张示例卡片不足以证明布局可用。本次结构与验收见 [目录、战斗与资料工作区](目录战斗与资料工作区.md)。

## 人物目录与命刻横条（0.1.5）

人物按已有 `Character.kind` 分为玩家角色、非玩家角色两个目录，分别显示数量；搜索、按当前类别新建、关闭入口固定，只有条目区滚动。条目保留持有人、公开／私密、在场、可见资源与有权执行的编辑／登场操作。GM 可在人物卡中修改类别；分类与战斗阵营独立。旧人物保留已有类型，不重建人物卡。玩家端沿用服务器的私密过滤，NPC 隐藏数值不显示。

命刻排序与兼容字段见 [命刻与冒险日志](命刻与冒险日志.md)；本次验收见 [人物分类与命刻横条验收](../人物分类与命刻横条验收-2026-10-12.md)。
