# 大厅、世界扩展与游玩工作区

来源：2026-10-13 用户新要求，覆盖早期每世界独立口令＋邀请码、资源堆叠及战斗行动弹窗。方格探索 0.1.7 已实现，在此基础继续。

## 本次交付边界

1. 大厅展示可进入世界、最近加入和自己管理的世界；刷新/重新进入可以恢复所在世界。GM 设置世界密码，留空开放；加入不再使用邀请码。用户已选定统一账号登录后进世界；凭旧世界口令或原签名会话绑定旧身份，保留原 GM/玩家身份与世界存档。
2. 参考 AAF 的世界扩展注册与开关方式，在创建世界和世界设置勾选 FU 扩展。启用后对应职业/技能/规则资源进入角色创建；关闭不静默删除已有角色选择。独立站不依赖 AAF/DND 运行时或导入其职业数据。
3. 全部 FU 扩展资料重建语义标题、段落、表格和分层目录；目录定位到具体条目，长文按章节切分，来源定位保留。
4. 参考 AAF/DND 的角色卡层级，固定人物身份和重要数值，分区处理属性、职业、装备、背景、立绘、自定义。角色行动中 HP/MP/IP/物语点视觉区分，能力可搜索分类，掷骰和资源调整独立分区。
5. 右侧记录分为系统日志、场内聊天、场外聊天、掷骰、战斗日志。场内默认角色身份，场外默认玩家身份；身份由服务器验证。人物创建、世界进入/离开等归系统；声明、战斗回合和数值结算归战斗。
6. 顶部命刻条适当增高。冲突命刻绑定场景，上半场显示在对方左侧空位，下半场显示在我方右侧空位；GM 选择半场。鼠标悬停/键盘聚焦显示加减快捷控制，触屏有可见入口；只能手动推进。
7. 冲突能力、骰子和资源操作使用向上滑出的非模态抽屉，舞台仍可选择人物、聊天和查看命刻；关闭按钮和 Esc 可用，不调用锁屏 dialog。
8. 已部署的 0.1.6 Windows 服务通过独立升级包更新到 0.2.0。升级前备份原程序、配置和数据；保留世界、上传素材、服务器密钥、运行环境与原访问地址。新版启动失败时恢复原程序。完整操作见 `../../deploy/升级说明.md`。
