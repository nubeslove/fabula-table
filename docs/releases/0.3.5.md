# 最终物语 0.3.5 · 小剧场动作修复与操作避让

修复小剧场动作在服务器与玩家电脑时间不一致时完全不播放的问题，同时把挡住立绘的工具浮层改为台词框下方的横向操作区。

- 走位、动作、通用表情在台词框下方展开，人物与表情保持在上方可见。宽屏动作六列两行，窄屏使用有界条目区；停稳、清除和关闭固定可达。
- 动作有效性统一使用服务器时间，避免电脑时钟偏差造成静默丢弃。刷新不重播旧动作，重复点击可重播。
- 修复系统减少动画设置压过页面「动态开」的问题。页面的显式选择保存到本机；动态关闭时显示提示与开启按钮。
- 震惊实际左右颤动两次（左右各 16 像素）并归位；保留轻跳、摇头、点头、鞠躬等共 12 种实际立绘动作，以及对应表情。
- 人物边缘预留动作余量，避免晃动、跳起时贴边裁切。

验证：9 项小剧场测试、类型检查与构建通过；浏览器逐帧检查全部 12 种动作、模拟一分钟时钟偏差、检查减少动画开关与刷新恢复，并验收宽屏、矮窗口和窄屏布局。

从大厅的服务器管理升级，或用 update.bat 获取最新版；GitHub 下载慢时可下载 upgrade 升级包，解压至独立目录后运行 upgrade-windows.cmd，选择原安装目录。保留世界、账号和素材。升级完成后刷新网页。
